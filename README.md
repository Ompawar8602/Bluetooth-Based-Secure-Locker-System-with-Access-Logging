# Bluetooth-Based-Secure-Locker-System-with-Access-Logging
A secure embedded locker system built on the LPC2148 (ARM7TDMI-S) microcontroller, featuring two-factor authentication using Bluetooth (HC-05) and a 4×4 keypad. The system securely stores passwords in AT24C256 EEPROM, logs access events with RTC timestamps via UART, and controls a DC motor-based locking mechanism through the L293D driver
